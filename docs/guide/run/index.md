# Run CREST

Choose a workflow based on what you want to measure and what you already have.

| I want to… | What I need | Start here |
| --- | --- | --- |
| Run a first neural architecture search (NAS) | A workstation and the prepared OxIOD dataset | [Set up CREST](setup.md), then [run a first study](first-study.md) |
| Measure candidates on a microcontroller | A supported board and its toolchain. Energy measurements also require a harness and INA228 monitor. | [Run with hardware](hardware.md) |
| Inspect or compare existing results | A study database, trial CSV, or replay results, depending on the analysis | [Read study results](results.md) |
| Regenerate figures, rerun a study configuration, or replay candidates | Saved artifacts for analysis. Add prepared data and, where required, hardware for reruns. | [Reproduce an experiment](reproduce.md) |
